# Mascot images (optional)

Put transparent PNGs here and the app picks them up automatically. Without them, the app shows a
clay-style 🦥 tile instead, so nothing breaks.

| File | Where it appears |
|---|---|
| `sloth_logo.png` | Sidebar logo |
| `sloth_hero.png` | Welcome screen and Library header |
| `sloth_empty.png` | Empty library / no packets |
| `sloth_done.png` | Review queue empty |
| `sloth_built.png` | Packet built |
| `sloth.png` | Fallback for any of the above |

Keep each under ~300 KB. Everything loads from disk; nothing is fetched from the internet.
